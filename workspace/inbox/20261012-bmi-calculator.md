## 做什麼 / What to do

做一個簡單的 **BMI 計算器**網頁小應用（單一 HTML 檔，內含 CSS／JS，不需安裝任何東西）。

## 需求 / Requirements

1. 使用者輸入：**身高（公分）**、**體重（公斤）**。
2. 按下「計算」後顯示 BMI 數值（保留一位小數）與體位分級，採用台灣衛福部標準：
   - BMI < 18.5 → 過瘦
   - 18.5 ≤ BMI < 24 → 正常
   - 24 ≤ BMI < 27 → 過重
   - BMI ≥ 27 → 肥胖
3. 介面文字全部用**繁體中文（台灣用語）**，例如：「身高」「體重」「計算」「過重」（不用「过重」「标准」等簡體或非台用語）。
4. 基本防呆：空白、非數字、負數或不合理（如身高 > 300 公分）的輸入，要顯示錯誤提示，不能顯示亂算的結果。
5. 再按一次可「重設」清空輸入與結果。
6. 畫面乾淨即可，不追求花俏；手機開起來版面不亂掉（基本 RWD 即可）。

## 格式 / Format

- 一個新檔案放在 `workspace/outbox/`，檔名建議：`20261012-bmi-calculator.html`
- 另在檔案最上方用註解或同資料夾附一行交接說明（做了什麼、要注意什麼、能不能直接用）。

## 怎樣算做完 / Done looks like

- 用瀏覽器直接打開就能算，輸入合法數字會得到正確 BMI 與正確分級（可用身高 170、體重 65 自測：BMI ≈ 22.5 → 正常）。
- 無法計算的輸入會跳出提示而不是顯示結果。
- 全部介面文字為繁體中文（台灣用語）。
